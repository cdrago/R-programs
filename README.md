### K-Means Clustering Algorithm (`kmeans_algorithm.R`)
A complete implementation of the K-Means clustering algorithm from scratch in R. The script includes:

- **Full K-Means implementation** with customizable parameters:
  - Number of clusters (k)
  - Maximum iterations
  - Random seed for reproducibility
  
- **Four comprehensive examples**:
  1. Simple 2D clustering demonstration
  2. Clustering the classic Iris dataset
  3. Elbow method for determining optimal number of clusters
  4. Comparison with R's built-in kmeans() function

- **Features**:
  - Euclidean distance calculation
  - Iterative cluster assignment and centroid updates
  - Convergence detection
  - Within-cluster sum of squares (WCSS) calculation

**Usage:**
```R
source("kmeans_algorithm.R")

# Or run all examples:
Rscript kmeans_algorithm.R
```
